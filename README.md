# ЛР № 1. Прикладная задача на табличных данных — вариант 2 (кредитный скоринг)

Набор: Home Credit Default Risk, `application_train.csv` (307 511 заявок, 8,07 % дефолтов).
Решение: одобрить / отклонить заявку; C_FN = 100 000 ₽, C_FP = 15 000 ₽, порог 0,13.

| Файл | Содержание |
|---|---|
| `lab1_emelyanov.ipynb` | Весь код, выполняется сверху вниз (полный прогон ≈ 1,5 ч на 8 ядрах) |
| `features.py` | Подготовка признаков (нужна для загрузки модели) |
| `model.joblib` | Пайплайн «признаки + LightGBM + isotonic», порог, цены ошибок |
| `input_schema.json` | 120 входных признаков: тип, диапазон / значения |
| `experiments.csv` | Журнал экспериментов (69 записей) |
| `results.json`, `figures/` | Числа и рисунки для отчёта |
| `Отчёт_ЛР1_вариант2.pdf` / `.docx` | Отчёт |

Запуск:

    pip install -r requirements.txt
    # положить application_train.csv в data/ (или ноутбук скачает его через kagglehub с токеном Kaggle)
    jupyter nbconvert --to notebook --execute lab1_emelyanov.ipynb

Результат на тесте: ROC-AUC 0,7706 [0,7638; 0,7774], потери от ошибок −25,1 % относительно «одобрять всех».
